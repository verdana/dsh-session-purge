# 移入回收站弹窗 · 视觉重设计

> 状态：已落地到 `client/client.js`。静态预览见 `docs/popup-redesign/preview.html`。
> 设计技能：已加载 `ui-ux-pro-max`，用 `design_recommend` / `design_search` / `design_review` 做了方向与规范检索。
> 说明：本机沙箱拦截了浏览器启动，未生成像素截图；预览页由真实 CSS 与同结构标记组成，组件结构另由 `tools/dialog-ssr-probe.mjs` 验证。

## 1. 设计思路

原弹窗的问题不是“字太小”，而是**所有信息用同一种语气说话**：目录、值、说明都是正文，用户只能逐字读完才知道哪一条是重点。

重设计把它拆成四层，按“用户先问什么”排序：

1. **发生了什么** —— 标题“移入回收站”，16px / 600，是卡片里最重的字。
2. **对谁发生** —— 会话名，14px / 600，独立于属性行，先建立对象感。
3. **它的属性** —— “目录”“自动清理”作为安静的 label；“D:\lootboot”“保留 30 天”作为值。
4. **需要被看见的状态** —— 保留期用琥珀 badge；运行中、无法定位等终态用琥珀提示块或实心琥珀按钮。

视觉语言取 **Swiss 极简 + 桌面工具**：一张 404px 卡片、一个琥珀强调色、无多余描边；层级靠字号、字重、颜色和 4/8 间距，而不是靠给每行加框。设计库的推荐里出现过 Neumorphism，但它更适合移动端玩具感界面，不适合高密度桌面弹窗，因此未采用。

## 2. 信息结构

```
┌──────────────────────────────────────────┐
│  [icon]  移入回收站                       │
│          移入后可在回收站中随时恢复       │
│  ┌────────────────────────────────────┐  │
│  │  会话                              │  │
│  │  会话清理策略                      │  │
│  │  ────────────────────────────────  │  │
│  │  目录        D:\lootboot           │  │
│  │  自动清理    ● 保留 30 天          │  │
│  └────────────────────────────────────┘  │
│                        取消   移入回收站  │
└──────────────────────────────────────────┘
```

- 顶部 **header**：图标 + 标题 + 一句后果说明，回答“点下去会怎样”。
- 中部 **panel**：会话身份 + 两条属性。面板用极浅底色把“对象信息”从卡片 chrome 中托出来。
- 底部 **actions**：取消是幽灵按钮，确认是反色实心按钮；终态只有一个实心琥珀“关闭”。

## 3. 文本层级规格

| 层级 | 内容示例 | 字号 / 字重 | 行高 / 字距 | 颜色 | 作用 |
|---|---|---|---|---|---|
| 标题 H2 | 移入回收站 | 16px / 600 | 1.3 / -0.01em | label-primary | 第一视觉落点 |
| 副标题 | 移入后可在回收站中随时恢复 | 11.5px / 400 | 1.45 / 0 | 次级文字 | 解释后果，不抢标题 |
| Overline | 会话 | 10.5px / 600 | 1.4 / 0.08em，uppercase | 次级文字 | 小标签，建立分区 |
| 会话名 | 会话清理策略 | 14px / 600 | 1.4 / 0 | label-primary | 第二视觉落点 |
| Label | 目录 / 自动清理 | 10.5px / 600 | 1.6 / 0.06em，uppercase | 次级文字 | 安静地指路 |
| 值 | D:\lootboot | 12.5px / 500 | 1.55 / 0 | label-primary | 答案本身 |
| 路径值 | D:\lootboot | mono 11.5px / 500 | 1.55 / -0.01em，break-all | label-primary | 机器数据，等宽更易扫 |
| Badge | ● 保留 30 天 | 11.5px / 600 | 1.55 / 0 | label-primary on amber 14% | 唯一强调 |
| 提示条 | 会话正在运行…… | 11.5px / 400 | 1.55 / 0 | 次级文字 | 解释为什么不能点 |
| 错误条 | 请求失败…… | 11.5px / 400 | 1.55 / 0 | state-error-primary | 失败原因 |
| 按钮 | 取消 / 移入回收站 | 12.5px / 500（primary 600） | 1 / 0 | 见下 | 操作 |

**为什么 label 反而更小？** label 是“索引”，不是“内容”。10.5px / 600 / 大字距的 uppercase 在视觉上像一条细线，用户扫一眼就能定位到右侧的值；如果 label 和值一样大，两列会互相打架。

**为什么值只比 label 大 2px？** 因为值的区分不靠“巨大”，而靠 **颜色（primary vs 次级）+ 字重（500 vs 600 的小字号标签）+ 位置**。在 404px 卡片里继续放大值会显得笨重。

## 5. 色彩与强调

### 5.1 主题令牌

| 用途 | token | Light | Dark |
|---|---|---|---|
| 卡片底 | `--dsw-alias-bg-overlay` | #E9ECF2 | #61666B |
| 主文字 | `--dsw-alias-label-primary` | #0F1115 | #F9FAFB |
| 次级文字基色 | `--dsw-alias-label-secondary` | #61666B | #CFD3D6 |
| 细边框 | `--dsw-alias-border-l1` | rgba(0,0,0,.04) | rgba(255,255,255,.06) |
| 琥珀强调 | `--dsw-alias-state-warn-primary` | #F59E0B | #F59E0B |
| 错误 | `--dsw-alias-state-error-primary` | #EC1313 | #F25A5A |

深色卡片不是纯黑，而是宿主 `bg-overlay` 的中灰 #61666B；这是为了和 DSH 现有弹层保持一致，不另造一套深色。若产品希望近黑面板，改这一个 token 即可（见“待补充”）。

### 5.2 次级文字的对比度修正

直接把 `label-secondary` 铺在深色卡片上只有 **3.85:1**，对 10.5–11.5px 的小字不够。因此卡片内定义：

```css
--sd-dlg-secondary: color-mix(
  in srgb,
  var(--dsw-alias-label-secondary) 50%,
  var(--dsw-alias-label-primary)
);
```

- Light：#383C40 on #E9ECF2，约 **9.4:1**。
- Dark：#E4E7E9 on #61666B，约 **4.67:1**；在浅色 panel 上约 **4.54:1**，仍过 4.5:1。
- 对比：主文字 Light 15.97:1 / Dark 5.55:1；琥珀实心按钮文字 #1B1B1B on #F59E0B 为 **8.02:1**。

### 5.3 强调规则

1. **全卡只有一个琥珀强调**：保留期 badge。它回答“这条会话还能活多久”，是用户在这个弹窗里最想确认的数字。
2. **会话名不用颜色强调**，用 14px / 600 的字重；避免“到处都是重点”。
3. **路径用等宽字体**，但颜色仍是主文字；它重要在“可核对”，不需要抢眼。
4. **终态才用实心琥珀按钮**：运行中、无法定位、已排队；默认确认按钮用反色中性实心，避免把可逆操作做成危险红。
5. **关闭态降级**：`自动清理：已关闭` 渲染为灰色 muted badge，去掉琥珀圆点；信息还在，但不再占用注意力。

## 6. 状态

| 状态 | 表现 | 关键处理 |
|---|---|---|
| 默认（开启自动清理） | 琥珀 badge + 5px 圆点 + “保留 30 天” | 唯一强调 |
| 自动清理关闭 | muted badge，无圆点，“已关闭” | 不再用琥珀 |
| 会话运行中 | 琥珀 tint 提示条；确认按钮 disabled | 解释“结束后才能移入” |
| 已排队 | 中性提示条；只剩“关闭” | 不再显示策略行 |
| 无法定位 | 琥珀提示块；隐藏副标题与属性 panel；只剩实心琥珀“关闭” | 不再承诺“可恢复” |
| 请求失败 | 红色 tint 错误条；底部操作保留 | 错误不吞掉主操作 |
| 处理中 | 按钮 disabled，确认文案变“处理中…” | 禁止遮罩/Esc 关闭 |

## 7. 交互与无障碍

- `role="alertdialog"` + `aria-modal="true"` + 可见 H2；遮罩点击与 Esc 在非 busy 时关闭。
- 默认焦点落在“取消”（安全动作）；终态焦点落在“关闭”。
- `:focus-visible` 为 2px 主文字色 outline，offset 2px；不使用默认蓝环。
- 所有图标为同一套 16px 线性 SVG，不用 emoji。
- `prefers-reduced-motion: reduce` 关闭 180ms 入场动画。
- 32px 按钮是桌面指针目标；若该弹窗要上触摸设备，按 44×44 最小目标放大（待补充）。

## 10. 待确认 / 待补充

- **品牌色**：当前琥珀来自 DSH 的 `state-warn-primary`，不是品牌色。若产品有品牌主色，只替换强调色，不要改语义错误色（待补充：品牌 HEX）。
- **深色卡片基色**：当前沿用宿主 `bg-overlay` 的 #61666B 中灰；若设计要“近黑弹窗”，需改 token 并重新验对比度（待补充：目标深色值）。
- **触摸目标**：32px 按钮适合桌面；触摸端是否要 44px（待补充：平台）。
- **窗口最小尺寸**：卡片有 `max-width: calc(100vw - 40px)`，但 76px label 列在超窄屏或长英文 label 下是否需要改成上下堆叠（待补充：最小宽度 / 语言）。
- **“目录”和“保留 30 天”谁更重要**：当前把保留期做成 badge；若产品认为目录才是第一信息，应交换强调位（待补充：优先级）。
- **品牌字体**：当前使用系统栈；若品牌指定 Plus Jakarta Sans 等，需要确认中文回退与加载方式（待补充：字体资产）。
